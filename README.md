# tasteskills

Skills, data and evals that push AI-built interfaces past the generic default.

| Area | What it is |
| --- | --- |
| [`typography/`](typography/) | A short catalog of free, self-hostable typefaces that don't read as AI-generated, plus `/find-font`. Formerly `no-slop-type`. |
| [`color/`](color/) | A curated library of OKLCH color directions (ground + figure pairs), plus `/find-color`. Formerly `no-slop-color`. |
| [`lab/`](lab/) | Experiments on whole-page design quality: same brief, several models, blind ratings. |

Install instructions live in each area's README. Agents start at [`AGENTS.md`](AGENTS.md).
