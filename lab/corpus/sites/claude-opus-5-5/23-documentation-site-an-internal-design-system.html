Installation #

Lumen ships as a CSS package with optional framework bindings. Install it from the internal registry.

1. Configure the registry

# .npmrc
@lumen:registry=https://npm.internal.example/

2. Install the package

npm install @lumen/core @lumen/tokens

3. Import the styles

// app entry point
import "@lumen/tokens/css/variables.css";
import "@lumen/core/dist/lumen.css";

// Set the theme on the root element
document.documentElement.dataset.theme = "light"; // or "dark"

Principles #

These guide every decision in the system. When in doubt, refer back here.

Clarity first

Every element earns its place. Remove anything that doesn't help the user complete their task.

Accessible by default

Components meet WCAG 2.2 AA out of the box — keyboard, screen reader and contrast included.

Tokens over values

Never hard-code a color, size or duration. Use tokens so themes and updates propagate everywhere.

Compose, don't fork

Extend components through composition. If you need a variant, propose it upstream.

Typography #

Inter for interface text, JetBrains Mono for code. The scale follows a modular ratio tuned for UI density.

✓ Do
  • Use sentence case for headings and labels.
  • Keep body text at --text-md for long-form reading.
  • Limit line length to ~70 characters.
✕ Don't
  • Use more than three type sizes in one view.
  • Set body text below --text-sm.
  • Use all caps for anything longer than a label.

Spacing #

A 4px base grid. Use spacing tokens for margins, padding and gaps to keep rhythm consistent.

Tooltip Beta #

Modal Stable #

Modals interrupt the user for a focused decision. Focus is trapped inside and restored on close; Esc dismisses.

Toast Beta #

Brief, auto-dismissing confirmation of an action. Announced politely to assistive technology.

Accessibility #

Accessibility is a shared responsibility. Components give you a head start; your usage completes it.

AreaRequirement
ContrastText ≥ 4.5:1, large text and UI ≥ 3:1. All semantic text tokens pass in both themes.
KeyboardEvery interactive element reachable with Tab; visible focus ring via :focus-visible.
LabelsInputs use <label for>; icon-only buttons need aria-label.
MotionRespect prefers-reduced-motion; never auto-play motion longer than 5s.
AnnouncementsUse role="status" for non-urgent updates, role="alert" only for errors.
