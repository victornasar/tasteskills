Acme API Documentation

Version 2.1 · Base URL: https://api.acme.example/v2

The Acme REST API lets you programmatically manage users, projects, and tasks. All requests and responses use JSON over HTTPS. Resources are addressed by URL, and standard HTTP methods and status codes describe the outcome of each call.

Quickstart

Fetch the authenticated user with a single request:

curl https://api.acme.example/v2/me \
  -H "Authorization: Bearer $ACME_API_KEY" \
  -H "Accept: application/json"
const res = await fetch("https://api.acme.example/v2/me", {
  headers: {
    "Authorization": `Bearer ${process.env.ACME_API_KEY}`,
    "Accept": "application/json"
  }
});
const user = await res.json();
console.log(user);
import os
import requests

res = requests.get(
    "https://api.acme.example/v2/me",
    headers={
        "Authorization": f"Bearer {os.environ['ACME_API_KEY']}",
        "Accept": "application/json",
    },
)
res.raise_for_status()
print(res.json())

Authentication

Authenticate every request by sending your API key in the Authorization header as a bearer token. Keys are created in the dashboard under Settings → API Keys. 

Authorization: Bearer sk_live_EXAMPLE_KEY_REDACTED
Keep your keys secret. Do not embed API keys in client-side code, public repositories, or URLs. Rotate a key immediately if you suspect it has leaked.

Keys come in two forms:

PrefixEnvironmentUse
sk_live_ProductionReal data and billing.
sk_test_SandboxSafe for development and testing.

Rate Limits

Each key is limited to 600 requests per minute. Every response includes headers describing your current quota:

HeaderDescription
X-RateLimit-LimitMaximum requests allowed in the window.
X-RateLimit-RemainingRequests remaining in the current window.
X-RateLimit-ResetUnix timestamp when the window resets.
Retry-AfterSeconds to wait before retrying (sent with 429).

Errors

Errors return a non-2xx status code and a JSON body with a stable machine-readable code:

{
  "error": {
    "code": "validation_failed",
    "message": "The field 'email' must be a valid email address.",
    "param": "email",
    "request_id": "req_8f2a91c3"
  }
}
StatusCodeMeaning
400bad_requestMalformed JSON or invalid query parameters.
401unauthorizedMissing or invalid API key.
403forbiddenKey lacks permission for this resource.
404not_foundThe resource does not exist.
409conflictThe request conflicts with current state.
422validation_failedOne or more fields failed validation.
429rate_limitedToo many requests. Retry after Retry-After.
500internal_errorSomething went wrong on our side. Include the request_id when contacting support.

Pagination

List endpoints are paginated with cursors. Pass limit (1–100, default 20) and the cursor from the previous response's next_cursor field. When next_cursor is null, you have reached the last page. 

GET /v2/tasks?limit=50&cursor=eyJpZCI6MTAwfQ

{
  "data": [ ... ],
  "next_cursor": "eyJpZCI6MTUwfQ",
  "has_more": true
}

Users

Manage the people who belong to your organization.

GET /v2/users/{id}

Retrieve a single user by ID.

Path parameterTypeDescription
idstringThe user's unique identifier.
 
{
  "id": "usr_4Kd9Lq",
  "email": "jordan@example.com",
  "name": "Jordan Lee",
  "role": "admin",
  "created_at": "2026-03-14T09:21:07Z"
}
POST /v2/users

Create a new user in your organization.

Body fieldTypeRequiredDescription
emailstringyesMust be unique within the organization.
namestringyesDisplay name, 1–120 characters.
rolestringnomember (default) or admin.
 
curl -X POST https://api.acme.example/v2/users \
  -H "Authorization: Bearer $ACME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "sam@example.com", "name": "Sam Rivera", "role": "member"}'
const res = await fetch("https://api.acme.example/v2/users", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.ACME_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ email: "sam@example.com", name: "Sam Rivera", role: "member" })
});
const user = await res.json();
DELETE /v2/users/{id}

Remove a user from the organization. Returns 204 No Content on success.

Deleting a user revokes all of their API keys. This action cannot be undone.

Projects

Projects group related tasks together.

GET /v2/projects

List projects. Supports pagination and the optional status filter (active, archived).

curl "https://api.acme.example/v2/projects?status=active&limit=20" \
  -H "Authorization: Bearer $ACME_API_KEY"
PATCH /v2/projects/{id}

Partially update a project. Only include the fields you want to change.

curl -X PATCH https://api.acme.example/v2/projects/prj_9Xz2Qw \
  -H "Authorization: Bearer $ACME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Website Redesign v2"}'

Tasks

Tasks are the units of work inside a project.

POST /v2/tasks
Body fieldTypeRequiredDescription
project_idstringyesThe project the task belongs to.
titlestringyesShort summary of the task.
assignee_idstringnoUser ID to assign the task to.
due_datestringnoISO 8601 date, e.g. 2026-12-01.
 
curl -X POST https://api.acme.example/v2/tasks \
  -H "Authorization: Bearer $ACME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"project_id": "prj_9Xz2Qw", "title": "Draft launch copy", "due_date": "2026-12-01"}'

Webhooks

Subscribe to events to receive a POST to your endpoint whenever something changes. Each delivery includes an X-Acme-Signature header: an HMAC-SHA256 of the raw request body, keyed with your webhook secret. Verify it before trusting the payload. 

{
  "id": "evt_3Lm8Rt",
  "type": "task.completed",
  "created_at": "2026-11-17T14:02:55Z",
  "data": { "id": "tsk_71Ab0c", "project_id": "prj_9Xz2Qw" }
}

Supported events: user.created, user.deleted, project.updated, task.created, task.completed.
