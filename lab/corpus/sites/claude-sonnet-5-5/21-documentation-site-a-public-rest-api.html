Acme API Reference

A simple, predictable REST API for managing projects, with JSON responses and standard HTTP verbs.

Base URL for all requests:

https://api.example.com/v1
  • All requests and responses use application/json.
  • All requests must be made over HTTPS.
  • Timestamps are ISO 8601 in UTC.
This is an example reference. Replace api.example.com and the sample data with your own.

Authentication

Authenticate with a bearer token in the Authorization header. Create and revoke keys in your dashboard. Keep keys secret and never embed them in client-side code.

Authorization: Bearer YOUR_API_KEY

Requests without a valid key return 401 Unauthorized.

Errors

Errors use conventional HTTP status codes and return a JSON body.

{
  "error": {
    "type": "invalid_request",
    "message": "The 'name' field is required.",
    "param": "name",
    "request_id": "req_8f2a1c"
  }
}
StatusMeaning
400Malformed request or invalid parameters.
401Missing or invalid API key.
403Key lacks permission for this resource.
404Resource not found.
409Conflict with current resource state.
422Validation failed.
429Rate limit exceeded.
5xxServer error. Safe to retry with backoff.

Pagination

List endpoints use cursor-based pagination.

ParameterTypeDescription
limitintegerItems per page, 1–100. Default 20.
cursorstringValue of next_cursor from the previous page.
{
  "data": [ ... ],
  "has_more": true,
  "next_cursor": "c_9xKq2"
}

Rate limits

Each key is limited to 100 requests per minute. Every response includes:

HeaderDescription
X-RateLimit-LimitRequests allowed per window.
X-RateLimit-RemainingRequests left in the window.
X-RateLimit-ResetUnix time when the window resets.
Retry-AfterSeconds to wait (only on 429).

List projects

GET/projects

Returns a paginated list of projects.

Query parameters

NameTypeDescription
statusstringFilter by active or archived.
limitintegerSee pagination.
cursorstringSee pagination.

Example

curl https://api.example.com/v1/projects?status=active \
  -H "Authorization: Bearer YOUR_API_KEY"
const res = await fetch("https://api.example.com/v1/projects?status=active", {
  headers: { Authorization: "Bearer " + process.env.ACME_API_KEY },
});
const { data } = await res.json();
import os, requests

r = requests.get(
    "https://api.example.com/v1/projects",
    params={"status": "active"},
    headers={"Authorization": f"Bearer {os.environ['ACME_API_KEY']}"},
)
print(r.json()["data"])

Response 200

{
  "data": [
    {
      "id": "prj_1a2b3c",
      "name": "Website redesign",
      "status": "active",
      "created_at": "2026-03-14T09:30:00Z"
    }
  ],
  "has_more": false,
  "next_cursor": null
}

Create a project

POST/projects

Body parameters

NameTypeDescription
name requiredstringProject name, up to 120 characters.
descriptionstringOptional description.
metadataobjectUp to 20 key-value string pairs.

Example

curl -X POST https://api.example.com/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Website redesign", "description": "Q2 refresh"}'

Response 201

{
  "id": "prj_1a2b3c",
  "name": "Website redesign",
  "description": "Q2 refresh",
  "status": "active",
  "metadata": {},
  "created_at": "2026-03-14T09:30:00Z"
}

Retrieve a project

GET/projects/{id}
NameTypeDescription
id requiredstring (path)The project ID.
curl https://api.example.com/v1/projects/prj_1a2b3c \
  -H "Authorization: Bearer YOUR_API_KEY"

Returns the project object, or 404 if it does not exist.

Update a project

PUT/projects/{id}

Updates the supplied fields; omitted fields are unchanged.

NameTypeDescription
namestringNew name.
descriptionstringNew description.
statusstringactive or archived.
curl -X PUT https://api.example.com/v1/projects/prj_1a2b3c \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"status": "archived"}'

Delete a project

DELETE/projects/{id}

Permanently deletes a project. This cannot be undone. Returns 204 No Content on success.

curl -X DELETE https://api.example.com/v1/projects/prj_1a2b3c \
  -H "Authorization: Bearer YOUR_API_KEY"

Webhook events

Register an HTTPS endpoint in your dashboard to receive events as POST requests. Each request includes an X-Acme-Signature header, an HMAC-SHA256 of the raw body using your signing secret. Verify it before trusting the payload.

EventTriggered when
project.createdA project is created.
project.updatedA project is modified.
project.deletedA project is deleted.
{
  "id": "evt_77de",
  "type": "project.created",
  "created_at": "2026-03-14T09:30:01Z",
  "data": { "id": "prj_1a2b3c", "name": "Website redesign" }
}

Respond with a 2xx status within 10 seconds. Failed deliveries are retried with exponential backoff for up to 24 hours.
