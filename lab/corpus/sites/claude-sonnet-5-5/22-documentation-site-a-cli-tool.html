flux

A fast, zero-config build and deploy tool for modern projects. One command to scaffold, build, run, and ship.

⚡ Fast

Incremental builds with content-addressed caching.

🧩 Extensible

Plugins and hooks for custom workflows.

🔒 Reproducible

Lockfile-driven builds that behave the same everywhere.

Note This documentation describes a sample CLI named flux. Replace the name, commands, and options with those of your own tool.

Installation

flux requires Node.js 18+ or a standalone binary. Choose your preferred method:

$ npm install -g @flux/cli
$ brew install flux
$ curl -fsSL https://example.com/install.sh | sh

Verify the installation:

$ flux --version
flux 2.4.0

Quickstart

Create, build, and run a project in under a minute.

# 1. Scaffold a new project
$ flux init my-app
$ cd my-app

# 2. Build it
$ flux build

# 3. Start the dev server
$ flux run --watch

Your app is now served at http://localhost:3000.

Commands

All commands follow the pattern flux <command> [options].

CommandDescription
initScaffold a new project
buildCompile the project for production
runStart a local development server
deployPublish a build to a target environment
configRead and modify configuration

flux init

Create a new project from a template.

flux init [name] [--template <tpl>] [--no-git]
OptionDefaultDescription
--template, -tdefaultTemplate to use (default, minimal, api)
--no-git—Skip git repository initialization

flux build

Compile your project. Output goes to ./dist by default.

flux build [--out <dir>] [--minify] [--sourcemap] [--no-cache]
OptionDefaultDescription
--out, -odistOutput directory
--minifytrueMinify output
--sourcemapfalseEmit source maps
--no-cache—Disable the build cache

flux run

Start a development server with optional live reload.

flux run [--port <n>] [--host <addr>] [--watch] [--open]
OptionDefaultDescription
--port, -p3000Port to listen on
--hostlocalhostHost address to bind
--watch, -wfalseRebuild on file changes
--openfalseOpen the browser on start

flux deploy

Publish the current build to an environment defined in your config.

flux deploy <environment> [--dry-run] [--yes]
OptionDescription
--dry-runShow what would be deployed without making changes
--yes, -ySkip the confirmation prompt
Caution Deploying to production is not reversible from the CLI. Use --dry-run first.

flux config

Inspect or change configuration values.

$ flux config list
$ flux config get build.out
$ flux config set build.out ./public

Global Flags

These flags work with every command.

--versionPrint the version and exit

Configuration File

flux looks for flux.config.json in the current directory and walks up to find one. Command-line flags override file values.

{
  "name": "my-app",
  "build": {
    "out": "dist",
    "minify": true,
    "sourcemap": false
  },
  "run": {
    "port": 3000
  },
  "environments": {
    "staging":    { "target": "s3://my-bucket-staging" },
    "production": { "target": "s3://my-bucket-prod" }
  }
}

Using in CI

Example GitHub Actions workflow that builds and deploys on push to main:

name: deploy
on:
  push:
    branches: [main]
jobs:
  ship:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install -g @flux/cli
      - run: flux build --no-color
      - run: flux deploy production --yes
        env:
          FLUX_TOKEN: ${{ secrets.FLUX_TOKEN }}
Tip Store FLUX_TOKEN as an encrypted secret and never commit it to your repository.

Troubleshooting

Port already in use

Another process is using port 3000. Pick a different port with flux run --port 4000.

Stale build output

Clear the cache and rebuild:

$ flux build --no-cache

Debugging unexpected behavior

Run with verbose logging to see what flux is doing:

$ FLUX_LOG_LEVEL=debug flux build --verbose

FAQ

Does flux support monorepos?

Yes. Run commands from the package directory, or point to a package config with --config.

Can I use a config format other than JSON?

Not currently. Only flux.config.json is supported.

How do I upgrade?

Re-run your install command, e.g. npm install -g @flux/cli@latest.
