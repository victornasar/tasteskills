How that line was made

Three steps, from the event your product sends to the line your finance team signs off.

  1. 1

    Send events

    Post usage events from your product as they happen: POST /v1/events.

    POST /v1/events
{
  "customer": "acme",
  "metric":   "api_calls",
  "quantity": 1,
  "time":     "2026-03-14T09:21:07Z"
}

    Illustrative payload. The docs have the full schema.

  2. 2

    Define pricing

    Tiers, minimums, credits and commitments, written as rules you can read.

    rule API calls
    metric  api_calls
    price   $0.0004 per call

    The rule behind the example line above. Illustrative syntax.

  3. 3

    Invoice
