How it works

  1. 1

    Send events.

    Post usage events from your product as they happen: POST /v1/events.

    POST /v1/eventsExample request
    {
  "customer":        "cus_4821",
  "meter":           "api_calls",
  "quantity":        1,
  "timestamp":       "2026-03-14T09:21:07Z",
  "idempotency_key": "evt_7f3c2a91"
}
  2. 2

    Define pricing.

    Tiers, minimums, credits and commitments, written as rules you can read.

    pricing ruleExample
    price "API calls"
  meter   api_calls
  unit    $0.0004 per call
  period  monthly
  3. 3

    Invoice.

    Each line on an invoice opens up into the events that produced it.

    invoice lineExample
    API calls, March$481.76 1,204,388 calls × $0.0004 · 31 daily totals · see it above
