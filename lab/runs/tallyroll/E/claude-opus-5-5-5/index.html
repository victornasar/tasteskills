How an event becomes a line on an invoice.

  1. 01

    Send events.

    Post usage events from your product as they happen: POST /v1/events.

    POST /v1/events
Idempotency-Key: evt_0314_8f2c

{
  "customer":  "cus_4821",
  "metric":    "api_calls",
  "quantity":  1,
  "timestamp": "2026-03-14T09:21:07Z"
}

    Example request. Field names are illustrative; the docs have the schema.

  2. 02

    Define pricing.

    Tiers, minimums, credits and commitments, written as rules you can read.

    price api_calls
  per call   $0.0004
  billed     monthly

    Example rule for the invoice line above.

  3. 03

    Invoice.

    Each line on an invoice opens up into the events that produced it.

    API calls, March
  1,204,388 calls × $0.0004 = $481.76
  └─ 31 daily totals
     └─ the events behind each day
