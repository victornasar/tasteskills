How it works

Three steps, from event to invoice.

  1. 01

    Send events.

    Post usage events from your product as they happen.
    POST /v1/events

    # illustrative request
curl https://api.tallyroll.com/v1/events \
  -H "Idempotency-Key: evt_8f2c…" \
  -d customer=cus_123 \
  -d metric=api_calls \
  -d quantity=1
  2. 02

    Define pricing.

    Tiers, minimums, credits and commitments, written as rules you can read.

    tiersper unit, by volume
    minimumsfloor per period
    creditsapplied before billing
    commitmentsdrawn down over term
  3. 03

    Invoice.

    Each line on an invoice opens up into the events that produced it.

    invoice → line → daily totals → events
