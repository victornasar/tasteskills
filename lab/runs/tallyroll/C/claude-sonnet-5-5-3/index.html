How it works

Three steps, and the last one is the one finance reads.

  1. Send events.

    Post usage events from your product as they happen.

    POST /v1/events

  2. Define pricing.

    Tiers, minimums, credits and commitments, written as rules you can read.

  3. Invoice.

    Each line on an invoice opens up into the events that produced it.

For finance

  • Line-level audit trail
  • Exports to NetSuite and QuickBooks
  • Revenue recognition schedules

For engineering

  • Idempotent event ingestion
  • Webhooks for every invoice state
  • SDKs for TypeScript, Python and Go
