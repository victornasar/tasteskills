How it works

From usage event to invoice line, in three steps.

  1. Send events.

    Post usage events from your product as they happen: POST /v1/events.

    POST /v1/events
{
  "idempotency_key": "evt_8f2c1a",
  "customer": "cus_4021",
  "type": "api.call",
  "quantity": 1,
  "timestamp": "2026-03-14T09:21:07Z"
}
# Illustrative request. The docs have the full schema.

  2. Define pricing.

    Tiers, minimums, credits and commitments, written as rules you can read.

    meter   api_calls
  sum   quantity where type = "api.call"
price   $0.0004 per call
period  calendar month
# Illustrative rule, priced like the example invoice.

  3. Invoice.

    Each line on an invoice opens up into the events that produced it.

    1. API calls, March · $481.76Invoice line
    2. 31 daily totals · 1,204,388 callsOpens from the line
    3. api.call events · each with its idempotency keyOpens from each day
