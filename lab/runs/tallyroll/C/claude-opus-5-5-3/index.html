How it works

Events in, invoices out, nothing in between you can't inspect.

  1. 01

    Send events

    Post usage events from your product as they happen: POST /v1/events.

    # example request
POST /v1/events
Idempotency-Key: evt_8f2c41

{
  "metric": "api_calls",
  "customer": "cus_0193",
  "quantity": 1,
  "timestamp": "2026-03-14T09:21:07Z"
}
  2. 02

    Define pricing

    Tiers, minimums, credits and commitments, written as rules you can read.

    Rule syntax is in the docs.

    Invoice
