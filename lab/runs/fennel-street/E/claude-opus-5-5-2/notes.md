The page passed both fix rounds. I've saved it to `index.html` and `DIRECTION.md` in the project.



- **Order:** a phone visitor's questions set the order (is it open, where, what's baked, cakes). The first screen shows a live open/closed line and a 7:00–14:00 timeline marked bread, tarts and gone, with a dot for the current time.
- **Colour:** Club Cream (`lib.club-cream`), with Club Burgundy used as full-width bands, not thin accents. I chose it over the engine's default pick, Parchment and Ink, which only suits pages carried by photography.
- **Fonts:** Synonym for headings and Sentient for body text, both from Fontshare and declared to be self-hosted. They are **not embedded** because downloading them needed approval, so the page shows the system sans and Georgia until you add the woff2 files to `fonts/`.
- **Images:** no photo placeholders. The page uses an SVG drawing of a custard tart in burgundy line work and a "Fennel Street E8" sign; the photos to commission are listed in DIRECTION.md.
- **Checks:** the layout checker found none of the overused patterns on desktop or phone. In round 1 the phone number was missing from Find us, so I added it, then shortened the closed message and fixed the cake band alignment.
